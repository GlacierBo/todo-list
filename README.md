# Todo List

一个基于 Vue 3 和 Supabase 的现代化待办事项管理应用。

## 📚 文档

详细文档请查看 [docs/README.md](./docs/README.md)

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 📁 项目结构

详细的项目结构说明请查看 [docs/PROJECT_STRUCTURE.md](./docs/PROJECT_STRUCTURE.md)

简要结构：
```
todo-list/
├── config/          # 配置文件
├── src/             # 源代码
│   ├── components/  # Vue 组件
│   ├── composables/ # 组合式函数
│   ├── types/       # TypeScript 类型
│   └── utils/       # 工具函数
├── public/          # 静态资源
├── scripts/         # 脚本文件
└── docs/            # 文档
```

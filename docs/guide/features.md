# 功能特性

## 任务管理

### 添加任务

在输入框中输入任务内容，点击"添加"按钮或按 Enter 键即可创建新任务。

### 完成任务

点击任务前的复选框，可以标记任务为完成/未完成状态。已完成的任务会显示删除线。

### 删除任务

点击任务右侧的"删除"按钮，会弹出确认对话框，确认后任务将被删除。

## 优先级系统

TodoList 支持三种优先级：

- **🟢 低优先级** - 灰色标识，适合不紧急的任务
- **🟡 中优先级** - 黄色标识，适合一般重要的任务
- **🔴 高优先级** - 红色标识，适合紧急重要的任务

添加任务时，可以通过下拉选择框设置任务优先级。

## 数据持久化

所有任务数据都保存在浏览器的 LocalStorage 中：

- ✅ 刷新页面数据不会丢失
- ✅ 关闭浏览器后再打开数据依然存在
- ⚠️ 清除浏览器数据会导致任务丢失
- ⚠️ 不同浏览器之间的数据不共享

## 用户体验

- **响应式设计** - 适配各种屏幕尺寸
- **流畅动画** - 平滑的交互体验
- **确认对话框** - 防止误删除操作
- **空状态提示** - 友好引导用户添加任务

## 技术亮点

- 使用 Vue 3 Composition API
- TypeScript 类型安全
- 组件化设计，易于维护
- 本地存储，无需后端
